# Glosario

| Término | Significado |
|---|---|
| Datum | Referencia usada para medir una altura |
| Época | Período de validez de una referencia o configuración |
| Cadencia | Intervalo esperado entre mediciones |
| Frescura | Vigencia según hora observada, cadencia y retraso permitido |
| Tendencia | Diferencia entre lecturas comparables; no es un pronóstico |
| Umbral | Referencia revisada; no equivale a una orden oficial |
| CAP | Formato de mensajes oficiales de alerta |
| Bbox | Rectángulo geográfico: oeste, sur, este, norte |
| Checkpoint | Punto confirmado desde el cual continúa una ingesta |
| Cuarentena | Datos retenidos por problemas de calidad/contrato |
| AAB | Android App Bundle para distribuir mediante Google Play |
| Cierre técnico | Implementación verificada del alcance; no implica operación pública |
