# ADR-006 · Exploración espacial

**Lista implementada; cartografía opcional.** Propuesta original: 29/9/2026; ajuste D19: 4/10/2026.

API por bbox, filtros y lista accesible. MapLibre 0.22.0 permite un estilo configurado; no se contrató proveedor de tiles. OSM es una fuente de datos y MapLibre un motor, no un servicio de tiles incluido.

Elegir proveedor requiere atribución, privacidad, presupuesto y prueba Android. La lista mantiene la consulta sin ese servicio. Clusters quedan fuera del piloto pequeño.
