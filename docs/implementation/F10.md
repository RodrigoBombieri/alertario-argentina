# F10 — pruebas de sistema

**Estado al 4/10/2026:** iniciada de forma transversal, no aceptada. Las suites de contrato, integración PostgreSQL y Flutter/emulador cubren rutas sintéticas, corrección tardía, cuarentena, permisos, historial paginado, caché, episodios/outbox y flujo móvil. El flujo en emulador Android 16 ahora incluye selección de historial de 7 y 30 días y detalle de procedencia temporal por lectura. El health de almacenamiento se probó con base válida, sin conexión y con esquema sin migraciones; no expone la credencial en la respuesta. La [verificación desde base vacía](../../infrastructure/db/verify-fresh-migrations.ps1) aplicó 10 migraciones y cinco smokes; el outbox rechaza latest cambiado y fuente revocada. Este corte no certifica operación real ni accesibilidad completa.

El modo D15 se probó en API Production configurada para inicio: `mode=collecting`, `officialDataAvailable=false`, 337 puntos `synthetic=true` y 14 días exactos. El flujo de búsqueda, ficha, historial y favorito pasó en el emulador Android contra ese modo. Las pruebas no equivalen a validar 14 días de datos reales.
