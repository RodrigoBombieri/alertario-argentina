# F12 — beta

**Cierre vigente:** F12 cerrada técnicamente bajo D18/D19; ver [criterios, evidencia y activación externa](TECHNICAL-CLOSURE.md). Los párrafos siguientes conservan el detalle de implementación y antecedentes, subordinados al alcance vigente.

**Detalle de implementación al 4/10/2026:** Paquete técnico preparado; beta pública no iniciada. El titular confirmó Android primero y US$100/mes como tope para cotizar infraestructura; la [base operativa](F12-OPERATING-BASELINE.md) todavía requiere responsables y dispositivo físico. [ADR-008](../adr/008-hosting-beta.md) propone DigitalOcean como primera opción técnica. Las imágenes de API y worker se construyeron localmente y la API respondió sus endpoints de salud y estado desde un contenedor; el [Compose de beta](../../infrastructure/environments/beta/compose.yaml) aún no se desplegó. No hay contratación, región elegida, staging desplegado, series INA/PNA aprobadas ni usuarios piloto. La [consulta de condiciones INA/PNA y aclaración técnica del CAP SMN](../research/f1/OUTREACH.md) están preparadas; no fueron enviadas. Una licencia abierta aplicable al CAP bastaría para su uso, sin permiso individual. Esta página es la lista verificable para no confundir una demo sintética con beta.

D14 permite iniciar la beta sin mediciones oficiales. D15 llena la interfaz con una estación ficticia y 14 días horarios simulados mediante `ColdStart:Enabled=true`, rotulados como muestra. Esto no inicia un colector real ni representa cobertura. Los 14 días de datos reales se cuentan por separado desde que una fuente y serie estén habilitadas; la evaluación es criterio para activar sus cálculos, no requisito para instalar la app. No habilitar ingesta de una fuente sin sus condiciones aplicables ni activar cálculos o avisos sin sus revisiones.

## Gates de entrada

| Gate | Evidencia necesaria | Estado |
|---|---|---|
| Fuentes y semántica | Para la beta con muestra: no publicar fuentes ni avisos sin condiciones. Para activar cada integración: derechos, contrato, representatividad y semántica revisados; feed SMN completo antes de avisos | Demo D15 permitida; integraciones oficiales pendientes por motivos externos; [resolución](../research/f1/CLOSURE.md#faltantes-por-motivos-externos) |
| Producto | Alcance técnico D19 aceptado con suites/emulador; comprensión y accesibilidad física requieren participantes | Técnico cerrado; prueba ciudadana externa |
| Hosting | Comparar proveedor/región/coste, Worker siempre activo, PostGIS, TLS, backup externo, límites de gasto, secretos y salida; registrar decisión en `DECISIONS.md` | Comparación y opción provisional D17/ADR-008 documentadas; faltan checkout, región/latencia, privacidad, contrato, restore y responsable operativo |
| Operación | Scripts/health/runbooks y restore local verificados; staging, guardia y contacto requieren infraestructura/titular | Técnico cerrado; activación externa |
| Piloto | Instalación Android física, consentimiento/textos legales, métricas de consulta y canal de feedback | Pendiente; requiere dispositivo y usuarios. No se exige un plazo fijo de operación para iniciar la beta |

No publicar ni habilitar notificaciones reales para compensar un gate incompleto. Si SMN no entrega un feed completo, evaluar una beta limitada con enlace y cobertura explícita, pero no declarar completo el MVP de avisos solicitado.

**Salida de F12:** beta Android instalada y probada con incidentes, costos y feedback registrados, sin espera operativa fija; para cualquier serie que pase de muestra a cálculos, informe de 14 días de datos reales y aprobación semántica por serie. Una beta que solo muestra datos ficticios puede demostrar instalación y operación, pero no aceptación del MVP hidrológico ni de avisos.
