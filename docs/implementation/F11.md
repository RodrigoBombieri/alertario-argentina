# F11 — observabilidad y recuperación

**Cierre vigente:** F11 cerrada técnicamente bajo D18/D19; ver [criterios, evidencia y activación externa](TECHNICAL-CLOSURE.md). Los párrafos siguientes conservan el detalle de implementación y antecedentes, subordinados al alcance vigente.

**Detalle de implementación al 4/10/2026:** Implementación anterior al ajuste D19. El escritor emite contadores de lotes exitosos/fallidos, inserciones, revisiones y cuarentenas, y un histograma de duración mediante `System.Diagnostics.Metrics` (`AlertaRio.Ingestion`). No emite IDs de series ni instalaciones como etiquetas. Con DB configurada, el Worker escribe un heartbeat cada 30 s en la migración 0011; `/health/worker` responde 503 cuando no hay pulso reciente. El Worker sintético registra conteos estructurados. Existen [runbook de migraciones](../runbooks/F4-MIGRATIONS.md) y [runbook del outbox](../runbooks/F8-OUTBOX.md). Un [restore local aislado](../../infrastructure/db/verify-local-restore.ps1) conservó versiones y conteos sin tocar la base original; todavía no se ensayó un restore desplegado ni opera un dispatcher. `/health/storage` comprueba conexión y el conjunto exacto de migraciones esperado por este binario cuando hay persistencia configurada. Es un diagnóstico separado de `/health/live`, `/health/worker` y `/health/ready`.
