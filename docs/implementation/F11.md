# F11 — observabilidad y recuperación

**Estado al 4/10/2026:** iniciada, no aceptada. El escritor emite contadores de lotes exitosos/fallidos, inserciones, revisiones y cuarentenas, y un histograma de duración mediante `System.Diagnostics.Metrics` (`AlertaRio.Ingestion`). No emite IDs de series ni instalaciones como etiquetas. El Worker sintético registra conteos estructurados. Existe un [runbook de migraciones](../runbooks/F4-MIGRATIONS.md), aún sin ensayo de restore desplegado.
