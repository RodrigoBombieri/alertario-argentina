# F11 — observabilidad y recuperación

**Estado al 4/10/2026:** iniciada, no aceptada. El escritor emite contadores de lotes exitosos/fallidos, inserciones, revisiones y cuarentenas, y un histograma de duración mediante `System.Diagnostics.Metrics` (`AlertaRio.Ingestion`). No emite IDs de series ni instalaciones como etiquetas. El Worker sintético registra conteos estructurados. Existen [runbook de migraciones](../runbooks/F4-MIGRATIONS.md) y [runbook del outbox](../runbooks/F8-OUTBOX.md). Un [restore local aislado](../../infrastructure/db/verify-local-restore.ps1) reprodujo las versiones 0001–0010 y conteos de tablas sin tocar la base original; todavía no se ensayó un restore desplegado ni opera un dispatcher.
