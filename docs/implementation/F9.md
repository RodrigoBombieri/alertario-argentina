# F9 — históricos ampliados

**Estado al 4/10/2026:** iniciada, no aceptada. Hay una consulta paginada de solo lectura para series observadas aprobadas en el preview Development y una vista móvil básica de siete días; no hay backfill operativo ni selección de rangos/agregación.

`GET /v1/series/{id}/history?from=&to=&cursor=&limit=` exige instantes con offset explícito, rango máximo de 31 días y `to` no futuro; limita la página a 500. Ordena de nuevo a viejo y el cursor excluye el último instante entregado, sin repetirlo en la página siguiente. Lee únicamente observaciones instantáneas aceptadas de fuente con permiso aprobado, dentro de un snapshot de solo lectura. Revocar la fuente devuelve 404. La suite PostgreSQL verificó dos páginas, rango inválido y revocación. Producción permanece sin datos oficiales y responde 503.

La ficha Flutter permite abrir una lista de lecturas de los últimos siete días y cargar páginas anteriores dentro de ese rango. La lista muestra hora absoluta y marca los datos sintéticos. Requiere conexión: si falla la API, muestra un error y conserva solo las páginas ya visibles, sin afirmar que el histórico está actualizado. Una prueba de widget verificó la carga de dos páginas sin repetir el punto inicial.
