# F7 — mapas

**Estado al 3/10/2026:** iniciada, no aceptada. La consulta espacial y el fallback de lista están probados con fixtures sintéticos; no hay renderizador MapLibre, tiles autorizados ni clusters.

## Corte implementado

- [0006_station_map_index.sql](../../infrastructure/db/migrations/0006_station_map_index.sql) agrega un índice GiST de geometría al punto de estación, sin modificar la geografía almacenada.
- `GET /v1/stations/map?bbox=oeste,sur,este,norte&limit=` valida coordenadas finitas y ordenadas, rechaza cajas de más de 10° por eje y limita la respuesta a 500 estaciones. `PostgresStationMapReader` exige estación activa, punto y al menos una serie observada aprobada de fuente con permiso aprobado. Devuelve identidad, río y coordenadas, sin inferir un nivel o seguridad para el área.
- La ruta solo usa PostgreSQL en el preview `Development` existente. Producción sigue devolviendo 503. La prueba real PostGIS verificó bbox dentro/fuera, límite de entrada y revocación del permiso.
- Flutter presenta una lista accesible para explorar un bbox, seleccionar una estación y abrir la ficha aun sin tiles. La entrada manual del bbox es una herramienta de desarrollo, no la experiencia final.

## Pendiente para aceptar F7

| Trabajo | Estado / desbloqueo |
|---|---|
| MapLibre y tiles | Falta spike en dispositivos, proveedor de tiles con permiso, atribución y presupuesto. Las condiciones de licencia y cotización de proveedores son **faltantes por motivos externos**; resolver solicitándolas, evaluar opciones y registrar la elección en `DECISIONS.md` |
| Mapa ciudadano | Faltan viewport automático, clusters que no agreguen estados, filtros por río/provincia, selección y fallback ante caída de tiles |
| Datos y alcance | Faltan estaciones piloto, asociaciones revisadas y condiciones de publicación de F1/F3; la API espacial no publica datos reales |
| Validación | Faltan zoom, lectores de pantalla, tiles caídos, atribución y rendimiento en Android/iOS reales |

El fallback de lista permanece disponible cuando el mapa no pueda cargarse. No se usa infraestructura comunitaria de OpenStreetMap como backend de tiles de producción.
